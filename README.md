# WhatsApp Bridge v2.0 (Stable)

هذا هو السيرفر الناجح والمستقر لربط واتساب بمنصة N8N مع تجاوز قيود DNS و LID.

## 📁 محتويات المجلد:
1. **bridge.js**: الكود الرئيسي للسيرفر.
2. **Dockerfile**: ملف إعدادات التشغيل على Hugging Face.
3. **package.json**: ملف التبعيات البرمجية.
4. **hf_upload.py**: سكريبت لرفع السيرفر إلى Hugging Face.

1. **في ملف bridge.js**:
   - قم بتغيير رابط الـ Webhook الخاص بـ n8n (ابحث عن 
8n_hook).
   - قم بتعديل منطق أرقام الهاتف (نداء الدولة) إذا كنت خارج تركيا.
